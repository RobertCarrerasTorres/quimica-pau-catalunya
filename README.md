# Química PAU Catalunya 2027

Aplicació web en català per preparar la prova de Química de les PAU de Catalunya 2027.

## Desenvolupament

Projecte inicialitzat amb Next.js, React i TypeScript. Les funcionalitats s'aniran incorporant per fases: temari, exercicis, correcció assistida, seguiment de l'alumnat i calendari d'estudi.
